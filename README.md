# Carlos Ballesteros

I’m Carlos Ballesteros, a software engineer and technical lead with over 20 years of experience building products.

I created [KorGE](https://github.com/korlibs/korge), an open-source Kotlin Multiplatform game engine, and maintained its library ecosystem and international community for eight years (2017–2025). My work spans graphics, audio, I/O, serialization and developer tooling across desktop, web and mobile platforms.
